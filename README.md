# 스플렌더

보석을 모아 개발 카드를 사고, 카드로 다음 카드를 깎고, 귀족을 불러 15점을 먼저 넘기는 온라인 스플렌더입니다.

![타이틀](assets/screenshots/title.png)

## 플레이

https://splendor.41ways.workers.dev/

2~4인. 방 코드나 초대 링크로 붙고, 봇으로 채우면 혼자서도 연습할 수 있습니다. 계정은 없습니다.

## 규칙

차례마다 서로 다른 보석 3개 집기 / 같은 보석 2개 집기(4개 이상 남아 있을 때만) / 카드 사기 / 카드 킵하고 황금 받기 중 하나만 합니다. 산 카드는 그 색 보석을 영구히 대신해서 다음 카드가 점점 싸집니다. 귀족은 카드 색깔 수 조건을 채우면 차례를 쓰지 않고 저절로 옵니다. 15점을 넘긴 사람이 나와도 그 라운드가 끝날 때까지 진행하고, 가장 높은 점수가 이깁니다.

카드 그림은 이미지 파일 없이 전부 인라인 SVG로 그립니다.

혼자 연습(봇과)은 서버 없이 브라우저에서 돌아가고, 온라인 대전은 서버(Cloudflare Workers + Durable Object)가 판정을 맡습니다.

## 기술

정적 화면(`public/`)은 Cloudflare Workers 자산으로, 소켓과 상태 확인만 Durable Object 하나로 처리합니다. 로컬 개발은 Node(`server.js`)로 같은 `game.js`를 띄웁니다. 규칙 엔진(`rules.js`)과 봇(`ai.js`)은 순수 함수라 서버와 화면이 같이 쓰고, 화면 쪽은 심볼릭 링크로 원본을 그대로 참조합니다.

```bash
npm install
npm start        # http://localhost:8874
npm test         # 규칙 · 봇 · 서버 시나리오 테스트
```

배포:

```bash
./bump.sh              # 자산 캐시 무효화
npx wrangler deploy
```

## 알려진 제약

관전 모드가 없고, 판에서 빠지면 다시 들어올 수 없습니다. 무를 수도 없습니다. 방은 서버 메모리에만 있어서 배포하면 열린 방이 사라집니다. 이 게임을 직접 해 보지 않고 규칙만 보고 만들어서, 실제와 다르거나 어색한 점이 있으면 이슈로 알려주면 도움이 됩니다.
